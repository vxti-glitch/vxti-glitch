### 1. [Enterprise Help Desk Operations Lab](https://github.com/vxti-glitch/enterprise-helpdesk-operations-lab)

I built and locally tested a static console around 40 simulated ITSM cases with optional ServiceNow learning-instance staging mappings; the cases, people, assets, timestamps, and metrics are fictional, not employment or production evidence. [Live simulated console](https://vxti-glitch.github.io/enterprise-helpdesk-operations-lab/) · [Build and verification note](https://github.com/vxti-glitch/enterprise-helpdesk-operations-lab/blob/main/docs/HOW_I_BUILT_AND_VERIFIED_THIS.md)

### 2. [Network Troubleshooting Toolkit](https://github.com/vxti-glitch/network-troubleshooting-toolkit)

I built and tested a Python DNS/ICMP/TCP triage CLI plus a 12-scenario browser simulation; the browser results are synthetic, and one local CLI run proves only point-in-time behavior on an authorized machine. [Live simulated lab](https://vxti-glitch.github.io/network-troubleshooting-toolkit/) · [Build and verification note](https://github.com/vxti-glitch/network-troubleshooting-toolkit/blob/main/docs/HOW_I_BUILT_AND_VERIFIED_THIS.md)

### 3. [IT Support Knowledge Base Lab](https://github.com/vxti-glitch/IT-Knowledge-Base)

I built and tested a searchable static site from 38 support articles with explicit evidence states; all current articles are concept-reviewed, and a successful content check does not claim that each procedure was executed. [Live knowledge base](https://vxti-glitch.github.io/IT-Knowledge-Base/) · [Evidence-state policy](https://github.com/vxti-glitch/IT-Knowledge-Base/blob/main/HOW_THIS_KB_IS_VERIFIED.md)

### 4. [Offline Autopilot Intake and Import-File Validator](https://github.com/vxti-glitch/intune-autopilot-lab-kit)

I ran local parsing, strict CSV validation, report generation, automated tests, and a 12-scenario browser simulation; I did not register a tenant or demonstrate enrollment, profile assignment, compliance, apps, or device deployment. [Live simulated lab](https://vxti-glitch.github.io/intune-autopilot-lab-kit/) · [Build and verification note](https://github.com/vxti-glitch/intune-autopilot-lab-kit/blob/main/docs/HOW_I_BUILT_AND_VERIFIED_THIS.md)

### 5. [Windows First-Response System Snapshot](https://github.com/vxti-glitch/windows-system-health-checker)

I built, tested, and ran a safe-share snapshot for one authorized Windows machine; its one-second CPU and point-in-time resource thresholds are observations, not diagnoses or evidence of ongoing system health. [Privacy and test boundary](https://github.com/vxti-glitch/windows-system-health-checker#privacy-and-safe-sharing)

### 6. [Entra Access-Review Candidate Helper](https://github.com/vxti-glitch/entra-access-review-auditor)

I built and tested an offline CSV candidate helper that preserves unknown sign-in and owner data and attributes heuristic rules; its synthetic reports are not tenant audits, risk decisions, or authorization to change access. [Verification scope](https://github.com/vxti-glitch/entra-access-review-auditor#verification-scope)
